# Images for /v2/discord

Upload images straight into these folders (on GitHub: open the folder → **Add file → Upload files** → commit).
Name them with numbers, no gaps: `1.jpg`, `2.png`, `3.webp`, … (jpg, png, webp or jpeg all work).
The page finds them on its own, up to 60 per folder. No code to change.

- `bg/`: the dim collage behind the headline and video. Payout certificates, charts, Discord wins, Jean's photos.
  Until there's a `bg/1.*`, the page draws chart tiles there instead.
- `results/`: the "Real Messages From Members" wall further down the page, shown in number order.

Tips: screenshots look best around 600–1000px wide. Compress them (e.g. squoosh.app → WebP) so the page stays fast.
